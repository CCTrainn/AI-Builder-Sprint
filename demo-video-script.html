1. 오프닝

화면홈 화면에서 로고와 주요 메뉴를 천천히 보여준다.
내레이션“말대꾸는 외국인 유학생과 이주노동자가 근로자료를 모으고, 기록 사이에서 달라진 조건을 발견하고, 고용주와 해결을 위한 대화를 이어가도록 돕는 서비스입니다. 문제가 있다고 알려주는 데서 끝나지 않고 실제로 어떤 말을 해야 하는지, 해결될 때까지 다음 대화를 도와줍니다.”
0:20–1:10

2. 자료 모으기

화면 조작자료 모으기 → 근무자료 추가 → 근로계약서 업로드
자료 유형: 근로계약서 / 기준 날짜: 2026-07-01
화면 조작처리 완료 후 급여명세서 업로드
자료 유형: 급여명세서 / 기준 날짜: 2026-07-31
내레이션“근로계약서와 급여명세서를 올리면 OCR이 문서를 읽고 시급, 근무시간, 지급액 같은 조건을 추출합니다. 입력하는 날짜는 업로드 날짜가 아니라 자료가 실제로 적용된 기준 날짜입니다. 올린 자료는 뒤의 기록 비교와 대꾸 AI가 같은 근거로 사용합니다.”
실수 방지: 한 파일의 처리가 끝난 뒤 다음 파일을 올린다. 업로드 버튼을 연속 클릭하지 않는다.
1:10–1:50

3. 기록 비교하기

화면 조작기록 비교하기로 이동 → “계약서와 급여명세서의 시급 기록이 달라요” 선택
계약서 12,000원 / 급여명세서 10,500원 / 차이 1,500원을 확대해서 보여준다.
내레이션“계약서에는 시급 12,000원이지만 급여명세서에는 10,500원이 적용됐습니다. 말대꾸는 이를 곧바로 불법이라고 단정하지 않고, 어느 기록의 어떤 조건이 다른지 보여줍니다. 사용자는 기억이 아니라 실제 자료를 근거로 확인할 항목을 선택합니다.”
1:50–2:50

4. 대꾸 AI로 해결까지 대화하기

촬영 핵심: 근로자 문장은 가능한 한 실제 AI 추천을 선택한다. 아래 근로자 문장은 AI 출력이 이상할 때만 수정용으로 사용한다. 사장님 답변은 아래 버튼으로 복사한다.

첫 질문

사장님, 근로계약서에는 시급이 12,000원으로 적혀 있는데 이번 급여명세서에는 10,500원으로 계산되어 있습니다. 어떤 기준으로 계산된 것인지 확인 부탁드립니다.
내레이션“기록 차이를 선택하면 대꾸 AI가 관련 자료와 대화 맥락을 읽고 첫 확인 문장을 제안합니다. 추천 문장은 그대로 쓰거나 실제 말투에 맞게 수정할 수 있습니다.”

사장님의 한 번 거절

수습기간에는 원래 10,500원으로 계산해. 다른 직원들도 다 그렇게 했으니까 이번 급여는 다시 계산하기 어려워.
근로계약서에는 수습기간 시급을 10,500원으로 적용한다는 내용이 확인되지 않습니다. 계약서의 시급 12,000원을 기준으로 차액을 다시 계산하고, 정확한 지급 금액과 날짜, 수정된 급여명세서를 알려주세요.
내레이션“고용주가 관행을 이유로 한 번 거절해도 대꾸 AI는 대화를 끝내지 않습니다. 계약 기록을 근거로 필요한 조치와 금액, 날짜, 수정 문서를 한 번에 요청합니다.”

해결 약속 확정

차액은 123,000원이고 8월 17일에 계좌로 입금할게. 급여명세서도 수정해서 보내줄게.
확인했습니다. 차액 123,000원을 8월 17일에 계좌로 지급하고, 시급 12,000원이 반영된 수정 급여명세서를 함께 받는 것으로 기록하겠습니다.
내레이션“한 번의 후속 답장으로 차액, 지급 날짜, 지급 방식과 수정 자료가 구체화됐습니다. 이후에는 약속한 날짜에 실제 입금됐는지를 기록으로 확인합니다.”
2:50–3:30

5. 공동 경험 확인 및 공유

화면 조작공동 경험 페이지 → 유사한 시급 차이 사례 열기 → 준비한 자료와 해결 과정을 보여주기 → 내 경험 초안 확인 → 수정 → 확정 → 공유
내레이션“비슷한 상황을 겪은 사용자가 어떤 자료를 준비했고 어떤 질문으로 해결했는지 익명 경험에서 확인할 수 있습니다. 사건이 끝나면 내 기록과 대화를 바탕으로 경험 초안이 자동 작성됩니다. 사용자는 내용을 확인하고 수정한 뒤 하나의 경험으로 공유하며, 공유 후에도 계속 수정할 수 있습니다.”
개인정보 설명“원본 자료와 전체 대화는 공개되지 않습니다. 이름, 연락처, 계좌번호처럼 개인을 식별할 수 있는 내용은 제거하고 해결 과정만 공유합니다.”
3:30–3:50

6. 엔딩

화면홈으로 돌아와 말대꾸 로고를 보여준다.
최종 내레이션“말대꾸는 대신 싸워주는 서비스가 아닙니다. 내 기록을 근거로 질문하고, 회피에도 다시 묻고, 실제 해결까지 이어갈 수 있도록 다음 말을 함께 만듭니다. 한 사람의 말대꾸가 기록되고 공유되면 다음 사람에게는 자신의 권리를 말할 근거가 됩니다. 말대꾸가 모이면 권리가 됩니다.”
