# 공동 경험·익명 사례 기능 기획

상태: 팀 검토 전 (`NOT APPROVED`)

담당 역할: `ROLE-COMMUNITY-EXPERIENCE`

이 문서는 공동 경험 기능의 구현 허가 문서다. 아래 다섯 항목을 팀이 합의하고
상태를 `APPROVED`로 바꾸기 전에는 화면, API, DB 테이블을 구현하지 않는다.

## 1. 기능의 목적

- 결정 필요: 공동 경험이 사용자에게 해결해야 하는 가장 중요한 문제
- 결정 필요: 말대꾸 AI와 증거 지갑 다음에 이 기능이 이어지는 이유
- 금지: 고용주 공개 평가, 공개 비난, 자동 신고

## 2. 공유 단위와 제외 정보

- 결정 필요: 문제 유형, 기록 차이, 대화 과정, 해결 행동 중 무엇을 공유할지
- 반드시 제외: 원본 문서, 원본 대화 캡처, 이름, 연락처, 계좌번호,
  외국인등록번호, 정확한 주소, 특정 개인·사업장을 식별할 수 있는 정보

## 3. 개인정보 제거와 재식별 방지

- 결정 필요: 자동 제거 규칙과 사람이 최종 확인할 항목
- 결정 필요: 날짜·지역·업종·금액을 어느 수준까지 일반화할지
- 원칙: 사용자가 명시적으로 동의한 가공 정보만 공유

## 4. 검증과 신뢰도 표시

- 결정 필요: `사용자 작성`, `기록 근거 있음`, `운영 확인` 등 상태 정의
- 결정 필요: 공식 법령 근거와 개인 경험을 화면에서 구분하는 방법
- 금지: 개인 경험을 확정 판례 또는 법적 사실처럼 표시

## 5. 악용 방지

- 결정 필요: 허위 사례, 특정인 공격, 중복 게시물의 신고·숨김 기준
- 결정 필요: 게시 중단과 이의 제기 흐름
- 원칙: 실제 사업장명과 개인 식별 정보는 게시할 수 없음
