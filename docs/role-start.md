# 조원별 Codex 시작 문장

저장소를 받은 뒤 자신의 브랜치에서 아래 중 하나를 Codex에게 입력한다.

먼저 모든 조원은 최신 `develop`에서 자신의 기능 브랜치를 만든다.

```bash
git switch develop
git pull origin develop
git switch -c feature/역할-이름
```

공동 경험·증거 커뮤니티는 아직 담당 기능이 아니다. 별도 기획이 확정될
때까지 관련 화면, API, DB를 만들지 않는다.

## 백엔드 정보 적재

```text
나의 역할은 백엔드 정보 적재 담당이야.
AGENTS.md와 docs 폴더의 공통 문서를 읽어줘.
내 역할에 맞는 .codex/ROLE.md를 만들고,
내가 수정할 파일, 수정하면 안 되는 파일, 첫 번째 작업 3개를 알려줘.
아직 구현은 시작하지 마.
```
